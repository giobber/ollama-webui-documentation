# Come installare ollama
> Non useremo questa modalità di installazione per usare WebUI
> Open WebUI attualmente va in crash se non trova il link di ollama all'avvio e Windows apre prima Docker Desktop e dopo l'applicativo di Ollama
> Per ovviare alla cosa creeremo un docker container anche per ollama accessibile alla porta 7869

Andare su [ollama.com/download](https://ollama.com/download)
Scarica l'installer per il tuo sistema operativo (windows 11 è supportato)

Esegui l'installer e segui la procedura guidata

Ollama si avvierà all'avvio di windows e rimarra nella barra degli strumenti
